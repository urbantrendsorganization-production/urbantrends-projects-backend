# Project Overview
This is a Django-based backend project for Urbantrends Blogs APIs. It follows the standard Django structure.

# Building and Running
- **Run Development Server:** `python manage.py runserver`
- **Run Migrations:** `python manage.py migrate`
- **Create Superuser:** `python manage.py createsuperuser`
- **Run Tests:** `python manage.py test`

# Development Conventions
- **Framework:** Django 6.0.5
- **Language:** Python
- **Database:** SQLite (default for development)
- **Structure:**
    - `accounts/`: Application for managing user accounts and authentication.
    - `urbantrends_blogs_apis/`: Main project configuration directory.
    - `manage.py`: Django command-line utility.
